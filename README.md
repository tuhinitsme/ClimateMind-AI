# ClimateMind AI

Predict. Prepare. Protect.

## Overview

ClimateMind AI is a GenAI-powered climate resilience platform that helps communities prepare for cyclones, floods, flash floods, and heatwaves through localized risk intelligence and preparedness recommendations.

## Problem

Millions receive disaster warnings but often lack clear, location-specific guidance on what actions to take.

## Solution

ClimateMind AI transforms weather forecasts, hazard information, and geospatial intelligence into actionable preparedness plans using Google Gemini.

## Features

- Climate risk assessment
- Disaster preparedness recommendations
- Location-aware alerts
- Interactive risk visualization
- Gemini-powered guidance

## Technology Stack

- Google Gemini
- Google Cloud
- React
- Node.js
- Firebase / Cloud Run
- GIS Datasets
